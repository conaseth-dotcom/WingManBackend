## 🤝 Autonomous Handoff Function
WingMan supports a physical, intuitive gesture for granting AI autonomy:

### **The Handoff Gesture**
When the user places a file or folder onto the AI Worktable, this action grants the AI permission to:
- create a sandbox copy of the item  
- modify, refactor, test, and iterate on the sandbox copy  
- act autonomously within the boundaries of the sandbox  

### **Sandbox Boundaries**
The AI may:
- freely modify sandbox files  
- generate new files  
- restructure the sandbox project  
- run multi-step workflows  

The AI may **not**:
- modify user originals  
- export files  
- access Hidden trays  
- modify RO trays  
- act outside the sandbox  
- escalate permissions  

### **User Sovereignty**
The user may at any time:
- revoke autonomy  
- delete the sandbox  
- request a rollback  
- request a summary of AI actions  
- request the AI forget the sandbox session  

### **Merge Workflow**
The AI may propose changes for merging back into a user tray.  
The user must explicitly approve all merges.
